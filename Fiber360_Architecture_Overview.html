Fiber360 Platform Architecture

AI-Powered FTTH Measurement

The phone measures → the server verifies → the cloud certifies. If three independent systems agree → it's valid. If they don't → it's flagged.
Anti-tamper by design. Engineers cannot type in measurements. The phone's AI measures. The server cross-validates. Multiple independent sources must agree within ±10% tolerance. Manual entry is blocked by default.

Measurement Engine
5 Independent Measurement Layers
Multiple independent sources cross-validate each measurement. No single source can be trusted alone — agreement across layers creates confidence.
LAYER 1 — ON DEVICE

AR Depth (ARKit / ARCore)

📱 Runs on phone — newer devices

Native Expo module. Tap two points in AR view → real-world distance. LiDAR on iPhone Pro gives cm-level accuracy. ARCore Depth API on 200+ Android devices.

±1cm (LiDAR) · ±5cm (non-LiDAR)
Fusion weight: 0.9 (LiDAR) · 0.7 (visual)
LAYER 2 — ON DEVICE

AI Depth (Depth Anything V2 Small)

📱 Runs on phone — ALL devices

25M param TFLite model. Instant depth map from any photo. Used for real-time preview guidance and auto-measurement with pixel-ratio calibration using industry standard infrastructure sizes.

±5-10cm (calibrated) — preview grade
Fusion weight: 0.3 (preview, low authority)
LAYER 3 — ON DEVICE

YOLO Object Detection (YOLOv8n)

📱 Runs on phone — ALL devices

6MB custom TFLite model trained on fiber infrastructure. 15 classes: manholes (EN 124), ducts (BS EN 61386), cables, trenches, reference objects, and defects. Auto-detects and auto-measures in real-time.

Detection: mAP@0.5 > 0.80
Fusion weight: 0.4 (auto-measure)
LAYER 4 — ON DEVICE

BLE Laser Meter

📱 Bluetooth — optional hardware

Leica DISTO D2 / Bosch GLM. Sub-millimeter precision laser measurement via Bluetooth. One-tap readings. The gold standard for validation — highest authority in fusion engine.

±0.5mm — sub-millimeter
Fusion weight: 1.0 (highest authority)
LAYER 5 — SERVER

Cloud AI (YOLO v2 + Grounding DINO)

🖥️ Runs on AWS — async verification

Dual-model architecture on 8GB instance. YOLO v2 for fast detection of 15 known classes (~200ms). Grounding DINO for zero-shot detection of any infrastructure via text prompt (~2-5s). Independent second opinion — tamper-resistant.

YOLO: higher mAP than mobile · DINO: any class
Fusion weight: 0.85 (high authority)
FUTURE — SERVER

Apple Depth Pro (400M params)

🖥️ GPU required — planned

Zero-shot metric depth estimation. Best boundary accuracy of any depth model. No calibration or reference objects needed — predicts absolute depth from focal length estimation alone. Requires GPU instance.

δ₁ = 0.89 on SUN-RGBD
Fusion weight: 0.90 (planned)
Fusion Engine
How Measurements Get Certified
Multiple sources feed into a weighted fusion algorithm. Agreement creates confidence. Disagreement creates flags.
🟢
Verified

≥3 independent sources agree within ±10%. High confidence. Weighted average gives final value. Auto-approved — no manual review needed.

🟡
Probable

2 sources agree, 1 diverges. Medium confidence. Final value from the 2 agreeing sources. Divergent source flagged for investigation.

🟠
Unverified

Only 1 source available. Accepted but marked for cloud verification. Common when offline — upgrades after server processes the photo.

🔴
Flagged

Sources contradict by >20%, or anomaly detector found tamper patterns (fake GPS, flat phone orientation, impossible velocity). Requires re-measurement or PM review.

Object Detection
15 YOLO Detection Classes
Custom-trained on fiber optic infrastructure. Detects, classifies, and measures automatically.
ACCESS POINTS

Manholes & Handholes

manhole_cover (EN 124 standard sizes), manhole_open, manhole_chamber, handhole — auto-measures diameter, depth, chamber dimensions.

CONDUIT

Ducts & Pipes

duct_single, duct_bundle, microduct — BS EN 61386 standard sizes. Auto-detects diameter, snaps to nearest standard (100mm, 110mm, 150mm).

CABLE

Fiber & Cable

fiber_cable, cable_tray — detects cable routing, bundle sizes, tray fill ratios for capacity planning.

EARTHWORKS

Trenches & Excavation

trench — auto-measures width and depth for PG114 compliance verification. Cross-references with spec ranges.

REFERENCE

Calibration Objects

measuring_tape, hard_hat, safety_cone — known real-world sizes used to auto-calibrate depth maps without user input.

DEFECTS

Damage Detection

crack, water_damage — identifies structural issues that need reporting. Flags for immediate attention in the portal.

Security
Anti-Tamper Chain
Every measurement carries a cryptographic provenance chain. Tampering breaks the chain.

📸 Photo Hash

SHA-256 of original photo bytes captured at measurement time. Any modification (crop, filter, edit) breaks the hash and invalidates the measurement.

📍 GPS + IMU

Lat/lng/altitude with accuracy. Accelerometer + gyroscope snapshot proves phone orientation (pointing at asset vs lying on desk). Detects impossible velocity.

⏱️ Timestamp Chain

Device time + NTP-verified server time. Future timestamps or stale submissions flagged. Can't backdate measurements.

🔗 Hash Linkage

Combined signature: hash(photoHash + depthHash + GPS + timestamp + measurements). Server stores hashes independently — any field modification breaks the chain.

☁️ Cloud Verification

Server runs same photo through independent AI models. Can't manipulate the cloud — different model, different hardware, different result. Must agree with on-device measurements.

🛡️ 8 Anomaly Checks

GPS null-island, IMU flat-phone, future timestamp, photo hash mismatch, impossible velocity, round-number bias, duplicate submission, batch pattern analysis.
